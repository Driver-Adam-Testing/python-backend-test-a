# Purpose
The provided script is a Bash shell script designed to automate the deployment of various components of a software application across different environments. It requires an environment argument to be passed when executing the script, ensuring that the deployment is targeted to the correct environment, such as development, staging, or production. The script sequentially navigates through several directories—`inspector`, `onboarding`, `pdf_preprocessing`, and `embedding`—and executes a `modal deploy` command on the `src/main.py` file within each directory, using the specified environment argument. This process facilitates consistent and efficient deployment of the application's components, ensuring that each part is correctly configured for the specified environment. The use of `set -e` ensures that the script will terminate immediately if any command exits with a non-zero status, preventing partial or inconsistent deployments.
