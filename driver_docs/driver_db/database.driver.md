## Folders
- **[alembic](database/alembic.driver.md)**: The `alembic` folder in the `python-backend` codebase is dedicated to managing database migrations using Alembic, featuring configuration scripts, a template for generating migration scripts, and a collection of migration scripts in the `versions` folder.
- **[nodes_v2_sql](database/nodes_v2_sql.driver.md)**: The `nodes_v2_sql` folder in the `python-backend` codebase contains SQL migration scripts for transitioning various data types, such as codebases, pages, templates, PDFs, tags, and top-level content, to a new database schema.
- **[utils](database/utils.driver.md)**: The `utils` folder in the `python-backend` codebase contains scripts for reindexing vector data in a PostgreSQL database, including a shell script for executing the reindexing process and a SQL script for recalculating and updating vector index parameters.
