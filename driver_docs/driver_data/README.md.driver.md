# Purpose
The provided content is a documentation snippet for a data migration utility within a software codebase. It describes a process for copying database and S3 records from a source to a destination, specifically for a given organization and codebase ID. The documentation highlights that the current implementation is limited to using localhost as the target due to AWS cross-account permissions issues. It provides command-line examples using the Poetry package manager to execute the data copying script, with options to skip downloading either database or S3 records. Additionally, it includes an example of a `.env` configuration file, detailing environment variables necessary for the operation, such as logging level, AWS credentials, and database connection URLs. This setup is crucial for developers to configure their local environment correctly to perform data migrations.
