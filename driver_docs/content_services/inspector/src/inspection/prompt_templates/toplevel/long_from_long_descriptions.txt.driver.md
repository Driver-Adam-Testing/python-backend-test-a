# Purpose
The provided content appears to be a template or guideline for documenting a software codebase. Its purpose is to instruct a documentation expert on how to write a comprehensive and detailed description of a software project. The template outlines a structured approach to documenting the codebase by breaking it down into several key components: the overall purpose and functionality of the codebase, the main business logic and logical flow, and the critical APIs or components. It emphasizes the importance of being selective and only including the most relevant information. Additionally, the template specifies that the documentation should be based solely on the provided descriptions of the modules, without making assumptions or adding unverified information. This ensures that the documentation is accurate and reliable, serving as a valuable resource for understanding and utilizing the software.
