## Folders
- **[agent](shared/agent.driver.md)**: The `agent` folder in the `python-backend` codebase contains classes and utilities for managing and interacting with language models from providers like OpenAI and Anthropic, including model configurations, tool definitions, and agent classes for handling API interactions and message processing.
- **[billing](shared/billing.driver.md)**: The `billing` folder in the `python-backend` codebase contains files that implement a billing service for managing subscription operations and define pricing tiers for consumption and seat pricing.
- **[chunking](shared/chunking.driver.md)**: The `chunking` folder in the `python-backend` codebase contains a file, `text_splitter.py`, which is responsible for splitting text into chunks and calculating token counts based on a specified model and token.
- **[embedding](shared/embedding.driver.md)**: The `embedding` folder in the `python-backend` codebase contains utilities for downloading content from S3 and generating text embeddings using OpenAI models, with support for both synchronous and asynchronous operations.
- **[file_storage](shared/file_storage.driver.md)**: The `file_storage` folder in the `python-backend` codebase contains files for managing AWS S3 operations, including an S3 client for bucket and object management and functionality for generating presigned URLs.
- **[interfaces](shared/interfaces.driver.md)**: The `interfaces` folder in the `python-backend` codebase contains various subfolders and files that define data models, configurations, and utilities for managing agent operations, billing, file content processing, usage metrics, AWS client configuration, driver requests and responses, and search operations.
- **[pipelines](shared/pipelines.driver.md)**: The `pipelines` folder in the `python-backend` codebase contains various Python scripts and modules for implementing agent-based tasks, block execution functions, file processing, and search functionalities, all integrated within a pipeline framework.
- **[prompts](shared/prompts.driver.md)**: The `prompts` folder in the `python-backend` codebase contains various subfolders and files that provide tailored prompts, define system interfaces, and manage technical content for different audiences and tasks, with an `__init__.py` file to initialize the package.
- **[repositories](shared/repositories.driver.md)**: The `repositories` folder in the `python-backend` codebase contains classes for managing database operations, including a generic `BaseRepository` for common SQLModel operations and a specialized repository for handling usage events.
- **[secret_management](shared/secret_management.driver.md)**: The `secret_management` folder in the `python-backend` codebase contains the `aws_secret_management.py` file, which provides functionality for managing secrets in AWS Secrets Manager.
- **[usage](shared/usage.driver.md)**: The `usage` folder in the `python-backend` codebase contains files that manage language model usage sessions, handle usage events and credits, and provide utility functions for code conversion.
- **[utils](shared/utils.driver.md)**: The `utils` folder in the `python-backend` codebase contains utility scripts and configurations, including text styling with ANSI codes, function decorators, Mermaid diagram rendering, OpenAI file uploads, and Puppeteer configuration.
- **[v3](shared/v3.driver.md)**: The `v3` folder in the `python-backend` codebase is a comprehensive package that includes components for managing data processing pipelines, defining constants and message classes, interacting with large language models, and conducting unit tests, all initialized and exposed through the `__init__.py` file.
