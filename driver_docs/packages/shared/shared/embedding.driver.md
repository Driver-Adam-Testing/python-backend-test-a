
## Files
- **[embed_helpers.py](embedding/embed_helpers.py.driver.md)**: The `embed_helpers.py` file contains functions for downloading source content files from an S3 bucket and generating embeddings for text strings by splitting the text and asynchronously embedding the chunks.
- **[text_embedder.py](embedding/text_embedder.py.driver.md)**: The `text_embedder.py` file provides synchronous and asynchronous functions for embedding text chunks using OpenAI's text embedding models, with support for error handling and batching.
