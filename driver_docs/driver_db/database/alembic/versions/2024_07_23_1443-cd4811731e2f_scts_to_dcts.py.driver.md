# Purpose
This code is a database migration script using Alembic, a lightweight database migration tool for SQLAlchemy. It provides narrow functionality, specifically designed to handle the migration of data between two tables: `source_content_types` and `derived_content_types`. The `upgrade` function copies all rows from `source_content_types` to `derived_content_types`, while the `downgrade` function reverses this action by deleting the copied rows from `derived_content_types`. The script includes metadata such as revision identifiers to track the migration's version and dependencies, ensuring that database schema changes are applied in a controlled and reversible manner.

# Functions

---
### downgrade 
The `downgrade` function removes rows from the `derived_content_types` table that have corresponding IDs in the `source_content_types` table.
- **Inputs**:
    - None
- **Control Flow**:
    - The function executes a SQL DELETE statement using Alembic's `op.execute` method.
    - The DELETE statement targets the `derived_content_types` table.
    - It removes rows where the `id` matches any `id` present in the `source_content_types` table.
- **Output**:
    - The function does not return any value; it performs a database operation to delete specific rows.


---
### upgrade 
The `upgrade` function copies all rows from the `source_content_types` table to the `derived_content_types` table.
- **Inputs**:
    - None
- **Control Flow**:
    - The function executes a SQL `INSERT INTO ... SELECT` statement using Alembic's `op.execute` method.
    - The SQL statement selects all columns (`id`, `type_name`, `created_at`, `updated_at`) from the `source_content_types` table.
    - The selected rows are inserted into the `derived_content_types` table with matching column names.
- **Output**:
    - The function does not return any value; it performs a database operation to copy data from one table to another.
