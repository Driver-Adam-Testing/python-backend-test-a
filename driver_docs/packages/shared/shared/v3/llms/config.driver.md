
## Files
- **[llm_config.py](config/llm_config.py.driver.md)**: The `llm_config.py` file defines a configuration system for large language models, including model providers, API versions, and supported models, with functionality to load configurations from a TOML file.
- **[llm_config.toml](config/llm_config.toml.driver.md)**: The `llm_config.toml` file in the `python-backend` codebase specifies configuration settings for various language models from providers like OpenAI and Anthropic, detailing parameters such as model IDs, context windows, output tokens, and API types.
