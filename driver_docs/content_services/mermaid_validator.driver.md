## Folders
- **[src](mermaid_validator/src.driver.md)**: The `src` folder in the `python-backend` codebase contains the `main.py` file, which is responsible for setting up a Modal application to validate Mermaid diagram syntax using a Node.js environment with the Mermaid CLI.

## Files
- **[poetry.lock](mermaid_validator/poetry.lock.driver.md)**: The `poetry.lock` file in the `python-backend/content_services/mermaid_validator` directory specifies the exact versions and dependencies of packages used in the project, ensuring consistent environments across different installations.
- **[pyproject.toml](mermaid_validator/pyproject.toml.driver.md)**: The `pyproject.toml` file in the `python-backend` codebase specifies the configuration for the `mermaid-validator` project, including its dependencies and build system settings.
