# Purpose
This Python script provides a narrow functionality focused on generating presigned URLs for accessing objects stored in an Amazon S3 bucket. It utilizes the `boto3` library to interact with AWS S3 and the `hashlib` library to create a hashed bucket name based on an organization ID. The script defines two functions: `generate_get_presigned_url`, which directly interfaces with the S3 client to create a presigned URL for a specified object key and bucket, and `get_presigned_url`, which hashes the organization ID to form a bucket name and then calls the first function to generate the URL. This code is particularly useful for securely granting temporary access to S3 objects without exposing AWS credentials.
# Imports and Dependencies

---
- `hashlib`
- `boto3`


# Functions

---
### generate_get_presigned_url 
The function generates a presigned URL for accessing an S3 object with a specified expiration time.
- **Inputs**:
    - `key`: The key (path) of the object in the S3 bucket for which the presigned URL is to be generated.
    - `bucket`: The name of the S3 bucket where the object is stored.
    - `expires`: The time in seconds for which the presigned URL is valid, defaulting to 3600 seconds (1 hour).
- **Control Flow**:
    - Create an S3 client using the boto3 library.
    - Call the 'generate_presigned_url' method on the S3 client with 'get_object' as the client method, passing the bucket name and key as parameters, and setting the expiration time.
    - Return the generated presigned URL.
- **Output**:
    - A string representing the presigned URL that allows access to the specified S3 object for the given expiration time.


---
### get_presigned_url 
The function `get_presigned_url` generates a presigned URL for accessing an S3 object using a hashed organization ID as the bucket name.
- **Inputs**:
    - `organization_id`: A string representing the unique identifier of the organization, which will be hashed to form the bucket name.
    - `path`: A string representing the path or key of the object in the S3 bucket for which the presigned URL is to be generated.
- **Control Flow**:
    - The function takes the `organization_id` and encodes it to bytes.
    - It computes the SHA-256 hash of the encoded `organization_id` and truncates the resulting hexadecimal string to 63 characters to form the bucket name.
    - The function calls `generate_get_presigned_url` with the `path` as the key and the hashed organization ID as the bucket name to generate the presigned URL.
    - The presigned URL is returned as the output of the function.
- **Output**:
    - A string representing the presigned URL for accessing the specified S3 object.
