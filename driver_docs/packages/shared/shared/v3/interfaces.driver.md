
## Files
- **[llm_message.py](interfaces/llm_message.py.driver.md)**: The `llm_message.py` file defines the `LlmMessage` class, which models messages with various kinds, including tool call requests and responses, and provides methods for creating instances from different message formats and printing them to the console.
- **[llm_message_history.py](interfaces/llm_message_history.py.driver.md)**: The `llm_message_history.py` file defines the `LlmMessageHistory` class, which manages a sequence of `LlmMessage` objects representing conversations or instructions, and provides methods for adding, removing, and converting these messages into formats compatible with various APIs like OpenAI and Anthropic.
- **[llm_message_kind.py](interfaces/llm_message_kind.py.driver.md)**: The `llm_message_kind.py` file defines an enumeration `MessageKind` that categorizes different types of messages such as user, assistant, developer, and system within the `python-backend` codebase.
- **[llm_parseable.py](interfaces/llm_parseable.py.driver.md)**: The `llm_parseable.py` file defines the `LlmParseable` class, a Pydantic base model that provides methods for auto-generating JSON instructions and example values for subclasses to facilitate interaction with language models.
- **[llm_response_type.py](interfaces/llm_response_type.py.driver.md)**: The `llm_response_type.py` file defines the `LlmResponseType` class, which serves as a base class for all response types and includes methods for converting instances to markdown and generating parsing description messages.
- **[llm_stream_response.py](interfaces/llm_stream_response.py.driver.md)**: The `llm_stream_response.py` file defines various classes for handling different types of stream responses in a large language model (LLM) system, including session management and error handling, with support for server-sent events (SSE) formatting.
- **[llm_tool.py](interfaces/llm_tool.py.driver.md)**: The `llm_tool.py` file defines an abstract base class `LlmTool` for tools that can be called by a language model, including methods for execution, error handling, and generating response messages.
