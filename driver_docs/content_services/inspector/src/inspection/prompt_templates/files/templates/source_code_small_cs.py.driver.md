# Purpose
This Python code file is a configuration script that defines a template for analyzing and documenting C# source code. It imports various modules and classes related to C# language specialization and default utilities, indicating its purpose is to facilitate the extraction and organization of information about C# code structures such as classes, structs, interfaces, and enums. The `SOURCE_CODE_SMALL_TEMPLATE_CS` variable is a list of tuples, each representing a section of the documentation template, including prompts for purpose, imports, and different C# constructs. The code provides narrow functionality focused on generating structured documentation for small C# codebases, leveraging both static analysis and language model insights.
