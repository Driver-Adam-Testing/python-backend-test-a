## Folders
- **[prompt_templates](inspection/prompt_templates.driver.md)**: The `prompt_templates` folder in the `python-backend` codebase contains subfolders with text files and templates designed to assist in inspecting, analyzing, and summarizing software code and metadata at various levels, including files, folders, and entire codebases.

## Files
- **[__init__.py](inspection/__init__.py.driver.md)**: Empty file (no analyzable contents).
- **[extensions.py](inspection/extensions.py.driver.md)**: The `extensions.py` file in the `python-backend` codebase lists various code and metadata file extensions, with notes indicating some may be removed as the logic is handled elsewhere.
- **[files.py](inspection/files.py.driver.md)**: The `files.py` file in the `python-backend` codebase provides functionality for determining file types and generating descriptions of files using language models, with support for various programming languages and metadata templates.
- **[folders.py](inspection/folders.py.driver.md)**: The `folders.py` file in the `python-backend` codebase provides functions for generating descriptions of folder contents using a language model, including handling content aggregation and compression for large data sets.
- **[symbols.py](inspection/symbols.py.driver.md)**: The `symbols.py` file in the `python-backend` codebase provides functionality for extracting and documenting symbols from source code files, including handling context extraction, symbol description generation using language models, and managing context size limitations.
- **[toplevel.py](inspection/toplevel.py.driver.md)**: The `toplevel.py` file in the `python-backend` codebase provides functions for generating and compressing descriptions of codebase content using a language model, including methods for creating various levels of detail from chunked descriptions.
