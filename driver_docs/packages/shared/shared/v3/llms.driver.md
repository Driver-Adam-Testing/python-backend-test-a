## Folders
- **[clients](llms/clients.driver.md)**: The `clients` folder in the `python-backend` codebase contains various Python files that define and implement clients for interacting with different language model APIs, including Anthropic's Claude and OpenAI's Chat and O-Series models, with support for synchronous and asynchronous operations, tool integration, and configuration-based subclass selection.
- **[config](llms/config.driver.md)**: The `config` folder in the `python-backend` codebase contains configuration files for large language models, including a Python script (`llm_config.py`) for defining and loading configurations and a TOML file (`llm_config.toml`) specifying settings for various model providers.
