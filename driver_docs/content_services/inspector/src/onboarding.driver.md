
## Files
- **[gh_ops.py](onboarding/gh_ops.py.driver.md)**: The `gh_ops.py` file in the `python-backend` codebase provides functions for interacting with GitHub, including generating JWTs, fetching access tokens, retrieving repository information, downloading repositories, and creating pull requests.
- **[gitlab_ops.py](onboarding/gitlab_ops.py.driver.md)**: The `gitlab_ops.py` file in the `python-backend` codebase provides functions for interacting with GitLab repositories, including fetching access tokens, downloading and uploading repositories, generating codebase metadata, and creating pull requests.
- **[languages.yml](onboarding/languages.yml.driver.md)**: The `languages.yml` file in the `python-backend` codebase defines various programming, markup, and data languages known to GitHub, including their properties such as file extensions, color representation, and syntax highlighting modes.
- **[onboard.py](onboarding/onboard.py.driver.md)**: The `onboard.py` file in the `python-backend` codebase handles the onboarding process for GitHub and GitLab repositories, including connecting, downloading, and processing repositories, as well as managing codebase connections and handling events related to repository changes.
- **[onboard_utils.py](onboarding/onboard_utils.py.driver.md)**: The `onboard_utils.py` file in the `python-backend` codebase provides a comprehensive set of utility functions for handling file operations, S3 interactions, and codebase processing, including tasks such as uploading and downloading files from S3, managing file encodings, and analyzing file types and sizes.
- **[push_bot.py](onboarding/push_bot.py.driver.md)**: The `push_bot.py` file in the `python-backend` codebase provides functionality for extracting values from a presigned URL, running shell commands, pushing documentation updates to GitHub or GitLab repositories, and handling S3 file downloads and directory synchronization.
- **[test_onboard_utils.py](onboarding/test_onboard_utils.py.driver.md)**: The `test_onboard_utils.py` file contains unit tests for the `unpack_archive_to_finalized_path` function, verifying its behavior when unpacking zip archives with various directory structures and optional override names.
