## Folders
- **[enums](static/enums.driver.md)**: The `enums` folder in the `python-backend` codebase contains a file, `format_kinds.py`, which defines an enumeration for categorizing various content formats.
- **[messages](static/messages.driver.md)**: The `messages` folder in the `python-backend` codebase contains Python files that define various message classes and systems for processing, editing, and generating technical documentation and content, often in the context of large language models (LLMs).
- **[response_types](static/response_types.driver.md)**: The `response_types` folder in the `python-backend` codebase contains Python files that define classes for handling specific response types, including information set definitions and list formatting.
- **[tools](static/tools.driver.md)**: The `tools` folder in the `python-backend` codebase contains Python files that implement various utility classes for generating folder summaries, performing hybrid searches, and opening files with specific functionalities.
