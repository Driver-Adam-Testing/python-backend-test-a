## Folders
- **[api](app/api.driver.md)**: The `api` folder in the `python-backend` codebase contains FastAPI route definitions, authentication and authorization middleware, logging middleware, API route configuration, and database session management functionalities.
- **[core](app/core.driver.md)**: The `core` folder in the `python-backend` codebase contains essential configuration and logging setup files, including a Pydantic-based settings manager and a console logger intended for deprecation.
- **[git_providers](app/git_providers.driver.md)**: The `git_providers` folder in the `python-backend` codebase contains various subfolders that manage GitLab-related configurations, OAuth strategies, provider operations, resource interactions, and utility functions.
- **[repositories](app/repositories.driver.md)**: The `repositories` folder in the `python-backend` codebase contains Python files that define repository classes and functions for managing database operations related to SQLModel-based models and Git provider applications, including GitHub app installations.
- **[schemas](app/schemas.driver.md)**: The `schemas` folder in the `python-backend` codebase contains various Pydantic models and related unit tests for handling user roles, codebase analysis, content operations, document sources, Git provider configurations, secret management, tagging, uploads, and user responses.
- **[services](app/services.driver.md)**: The `services` folder in the `python-backend` codebase contains various service implementations and their corresponding unit tests, including those for managing Auth0 operations, codebase analysis, content management, GitLab provider applications, tag management, and file uploads, along with utility functions for handling content names.
- **[tests](app/tests.driver.md)**: The `tests` folder in the `python-backend` codebase contains unit tests for repository CRUD operations and utility functions for authentication, with an empty `__init__.py` file.
- **[utils](app/utils.driver.md)**: The `utils` folder in the `python-backend` codebase contains utility modules for interacting with AWS S3, AWS Secrets Manager, and GitHub's API, facilitating operations such as managing cloud resources and handling API interactions.
