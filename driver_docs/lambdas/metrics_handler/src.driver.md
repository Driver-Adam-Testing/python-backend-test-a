## Folders
- **[utils](src/utils.driver.md)**: The `utils` folder in the `python-backend` codebase contains configuration management functionality using Pydantic, as indicated by the `config.py` file, alongside an empty `__init__.py` file.

## Files
- **[main.py](src/main.py.driver.md)**: The `main.py` file in the `python-backend` codebase is responsible for handling AWS Lambda events by logging event details and storing usage event data in a database using SQLModel.
