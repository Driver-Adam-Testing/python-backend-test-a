## Folders
- **[src](generation/src.driver.md)**: The `src` folder in the `python-backend` codebase contains the `main.py` file, which defines asynchronous functions for processing inline edits and smart instructions using modal functions with specified Docker images and secrets.

## Files
- **[poetry.lock](generation/poetry.lock.driver.md)**: The `poetry.lock` file in the `python-backend` codebase is a lock file generated by Poetry version 1.7.1, which manages and maintains the consistency of a Python project's dependencies across various environments by listing detailed package entries, dependencies, optional features, platform-specific builds, source information, hash verification, metadata, and Python version compatibility, ensuring a stable and reproducible environment.
- **[pyproject.toml](generation/pyproject.toml.driver.md)**: The `pyproject.toml` file in the `python-backend` codebase specifies the configuration for the `agent` project, including its dependencies, build system, and author information.
