
## Files
- **[event_metadata.py](usage/event_metadata.py.driver.md)**: The `event_metadata.py` file defines several Pydantic models for capturing metadata related to usage sessions, payment sessions, and events, as well as a method to convert usage metrics into usage events.
- **[usage_schema.py](usage/usage_schema.py.driver.md)**: The `usage_schema.py` file defines data models and utilities for handling usage metrics, events, and conversions between units such as bytes and SLOC within the `python-backend` codebase.
- **[usage_schema_test.py](usage/usage_schema_test.py.driver.md)**: The `usage_schema_test.py` file contains a suite of tests for validating the functionality of usage-related classes and conversion utilities in the `shared.interfaces.usage.usage_schema` module, using the pytest framework.
