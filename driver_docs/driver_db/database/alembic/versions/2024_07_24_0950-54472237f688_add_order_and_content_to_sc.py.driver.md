# Purpose
This code is an Alembic migration script used to modify a database schema, specifically for a table named `source_contents`. It provides narrow functionality focused on altering the structure of this table by adding two new columns, `order` and `content`, and adjusting indices related to the `content_type_id` column. The `upgrade` function implements these changes, including setting a server default for the `order` column, while the `downgrade` function attempts to reverse these changes, although it notes potential bugs. This script is part of a version-controlled database migration process, allowing for systematic updates and rollbacks of database schema changes.

### downgrade 
The `downgrade` function reverses database schema changes by dropping specific columns and modifying indices in the `source_contents` table.
- **Inputs**:
    - None
- **Control Flow**:
    - The function starts by dropping an index named `ix_source_contents_content_type_id` from the `source_contents` table.
    - It then creates a new index named `ix_source_contents_source_content_type_id` on the `source_contents` table for the `content_type_id` column, ensuring it is not unique.
    - The function proceeds to drop the `content` column from the `source_contents` table.
    - Finally, it drops the `order` column from the `source_contents` table.
- **Output**:
    - The function does not return any value; it performs schema modifications on the database.

### upgrade 
The `upgrade` function modifies the database schema by adding new columns, updating indices, and setting default values for a table named `source_contents`.
- **Inputs**:
    - None
- **Control Flow**:
    - Add a new column named 'order' of type Integer to the 'source_contents' table, allowing null values.
    - Add a new column named 'content' of type Text to the 'source_contents' table, allowing null values.
    - Drop the existing index 'ix_source_contents_source_content_type_id' from the 'source_contents' table.
    - Create a new index on the 'content_type_id' column of the 'source_contents' table with a non-unique constraint, using a function to generate the index name.
    - Alter the 'order' column in the 'source_contents' table to set a server default value of 0 for future inserts.
- **Output**:
