
## Files
- **[aws_s3_client.py](file_storage/aws_s3_client.py.driver.md)**: The `aws_s3_client.py` file implements an AWS S3 client for managing S3 buckets and objects, including creating buckets, generating presigned URLs, uploading files, and downloading files using presigned URLs.
- **[s3.py](file_storage/s3.py.driver.md)**: The `s3.py` file provides functionality to generate presigned URLs for accessing objects in an S3 bucket, using a hashed organization ID as the bucket name.
