## Folders
- **[legacy](routes/legacy.driver.md)**: The `legacy` folder in the `python-backend` codebase contains various Python files that define GraphQL types, mutations, queries, and schemas using the Strawberry library, manage Auth0 organizations and users, handle document sets and S3 interactions, and implement logging and custom scalar types for a FastAPI application.
- **[v1](routes/v1.driver.md)**: The `v1` folder in the `python-backend` codebase contains a collection of FastAPI route definitions for various functionalities, including agent execution, codebase management, content handling, document source management, Git provider operations, health checks, onboarding processes, organization management, search capabilities, subscription handling, tag management, file uploads, usage tracking, and user account operations.
- **[v2](routes/v2.driver.md)**: The `v2` folder in the `python-backend` codebase contains a collection of FastAPI-based API route definitions and utility functions for managing various entities such as autodocs, chat requests, content, document sources, nodes, primary assets, tags, and versions, with integration to databases and external services like AWS S3.
