# Purpose
The `.ruff.toml` file is a configuration file for the Ruff linter, which is used to enforce coding standards and identify potential issues in Python codebases. The file specifies a line length of 88 characters and targets Python version 3.12, with automatic fixing enabled. It defines a set of linting rules to select, including common error and warning categories, as well as additional rules from various Flake8 plugins and other tools. Certain rules are explicitly ignored, such as warnings about using function calls as default arguments and missing type annotations for `self` and `cls`, to accommodate specific project needs or coding practices. Additionally, the file specifies that some issues, like commented-out code, should not be automatically fixed, and it includes per-file ignores to exempt specific files, such as Alembic migration scripts, from certain checks.
