## Folders
- **[agent](content_services/agent.driver.md)**: The `agent` folder in the `python-backend` codebase contains the main source code for setting up a modal interface and executing block kind agents, along with testing scripts and configuration files for dependency management and project setup.
- **[autodocs](content_services/autodocs.driver.md)**: The `autodocs` folder in the `python-backend` codebase is dedicated to generating structured documentation using AI models, with a `src` folder containing configuration files and scripts, and includes `poetry.lock` and `pyproject.toml` files for managing project dependencies and metadata.
- **[generation](content_services/generation.driver.md)**: The `generation` folder in the `python-backend` codebase contains the `src` directory with the main processing logic for inline edits and smart instructions, alongside configuration files like `poetry.lock` and `pyproject.toml` for managing project dependencies and settings.
- **[inspector](content_services/inspector.driver.md)**: The `inspector` folder in the `python-backend` codebase contains modules and scripts for code inspection, onboarding, and utility functions, configuration files for the `uctags` component, and essential project files like `poetry.lock`, `pyproject.toml`, and `README.md` for managing dependencies and providing installation and deployment instructions.
- **[mermaid_validator](content_services/mermaid_validator.driver.md)**: The `mermaid_validator` folder in the `python-backend` codebase contains the source code and configuration files necessary for setting up a Modal application to validate Mermaid diagram syntax using a Node.js environment.
- **[onboarding_event_handler](content_services/onboarding_event_handler.driver.md)**: The `onboarding_event_handler` folder in the `python-backend` codebase contains the source code and tests for handling AWS SNS-triggered S3 events related to asset onboarding, along with configuration files for managing project dependencies and metadata.
- **[pdf_preprocessing](content_services/pdf_preprocessing.driver.md)**: The `pdf_preprocessing` folder in the `python-backend` codebase is designed for processing PDF files, managing dependencies, and configuring project settings, with a focus on handling PDF-related tasks and maintaining consistent builds.

## Files
- **[modal_deploy.sh](content_services/modal_deploy.sh.driver.md)**: The `modal_deploy.sh` file is a bash script that automates the deployment of multiple services by executing the `modal deploy` command with a specified environment argument for each service's `src/main.py` file in the `python-backend` codebase.
