
## Files
- **[auth0_schema.py](schemas/auth0_schema.py.driver.md)**: The `auth0_schema.py` file defines Pydantic models for handling user invitations and role modifications, including classes for invitees, invitations, and user role changes.
- **[codebase_schema.py](schemas/codebase_schema.py.driver.md)**: The `codebase_schema.py` file defines various Pydantic models for handling requests and responses related to codebase analysis, generation, and onboarding, including metrics calculations for source lines of code.
- **[codebase_schema_test.py](schemas/codebase_schema_test.py.driver.md)**: The `codebase_schema_test.py` file contains unit tests for the `CodebaseAnalysisMetrics` class, verifying its data integrity and immutability using pytest.
- **[content_schema.py](schemas/content_schema.py.driver.md)**: The `content_schema.py` file defines various Pydantic models for handling content-related operations, including listing, tagging, creating, and exporting content within the `python-backend` codebase.
- **[document_source_schema.py](schemas/document_source_schema.py.driver.md)**: The `document_source_schema.py` file defines a Pydantic model `DocumentSourceCreate` for creating document sources with fields for `document_id`, `source_id`, and an `include` flag.
- **[git_provider_schema.py](schemas/git_provider_schema.py.driver.md)**: The `git_provider_schema.py` file defines various Pydantic models for representing Git provider configurations, repositories, access tokens, and webhook information within the `python-backend` codebase.
- **[secret_management_schema.py](schemas/secret_management_schema.py.driver.md)**: The `secret_management_schema.py` file defines constants for secret name prefixes related to Git provider applications and installations.
- **[tag_contents_schema.py](schemas/tag_contents_schema.py.driver.md)**: The `tag_contents_schema.py` file defines a Pydantic model `TagContentCreate` for creating tag content associations with fields for `tag_id`, `content_id`, and an `include` flag.
- **[tag_schema.py](schemas/tag_schema.py.driver.md)**: The `tag_schema.py` file defines Pydantic models for handling tag-related data, including input validation and result structures for listing tags and their contents.
- **[upload_schema.py](schemas/upload_schema.py.driver.md)**: The `upload_schema.py` file defines Pydantic models for handling upload requests and responses, including validation to ensure the file path is a zip or pdf file.
- **[user_schema.py](schemas/user_schema.py.driver.md)**: The `user_schema.py` file defines a Pydantic model `MessageResponse` with a single string field `message`.
