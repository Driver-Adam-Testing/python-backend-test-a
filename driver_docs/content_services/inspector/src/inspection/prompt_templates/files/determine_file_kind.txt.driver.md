# Purpose
The provided content is a set of instructions for a software engineering expert to classify a given file based on its content type. The file content is evaluated to determine whether it is a large source code file, a small source code file, or a metadata/configuration file. The instructions detail the characteristics of each file type, such as the complexity and nature of the content, and specify the expected response format, which is a single integer (0, 1, or 2) corresponding to the identified file type. This document serves as a guideline for automated or manual classification of files within a software codebase, ensuring consistent categorization based on predefined criteria.
