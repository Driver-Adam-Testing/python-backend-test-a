# Purpose
The provided content is a Dockerfile, which is used to automate the creation of a Docker image for a Python application. It starts by using a lightweight Python 3.12 base image and sets the working directory to `/app/`. The file installs necessary system packages and the Python dependency management tool, Poetry, configuring it to avoid creating virtual environments. It then copies various components of the application, including the `driver_db` package, other packages, and the main application code, into the image. The Dockerfile also includes logic to install dependencies based on an `INSTALL_DEV` argument, allowing for different setups for development and production environments. Finally, it sets up executable start scripts and cleans up unnecessary packages to reduce the image size, concluding with a command to run the appropriate start script based on the environment configuration.
