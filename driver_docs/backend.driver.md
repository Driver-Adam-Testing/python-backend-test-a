## Folders
- **[app](backend/app.driver.md)**: The `app` folder in the `python-backend` codebase is a comprehensive component that includes FastAPI route definitions, core configurations, Git provider management, database operations, Pydantic schemas, service implementations, utility functions, and testing infrastructure, along with initialization scripts for setting up the application and its database.
- **[scripts](backend/scripts.driver.md)**: The `scripts` folder in the `python-backend` codebase contains various Python and shell scripts for database and S3 operations, server configuration, code linting, WebSocket interaction, application startup, and testing with coverage reporting.

## Files
- **[.dockerignore](backend/.dockerignore.driver.md)**: The `.dockerignore` file in the `python-backend` codebase specifies files and directories to be excluded from Docker builds, such as Python cache files, virtual environments, and coverage reports.
- **[.gitignore](backend/.gitignore.driver.md)**: The `.gitignore` file in the `python-backend` codebase specifies files and directories to be ignored by Git, including cache files, coverage reports, and virtual environment directories.
- **[poetry.lock](backend/poetry.lock.driver.md)**: The `poetry.lock` file in the `python-backend` codebase is a configuration file generated by the Poetry tool that locks specific versions of dependencies, providing comprehensive metadata, dependency management, optional extras, file integrity verification, metadata and Python version compatibility, and source information to ensure a stable and reproducible development environment across different systems.
- **[prestart.sh](backend/prestart.sh.driver.md)**: The `prestart.sh` file is a shell script that initializes the database by starting it, running migrations, and creating initial data.
- **[pyproject.toml](backend/pyproject.toml.driver.md)**: The `pyproject.toml` file in the `python-backend` codebase specifies the project's metadata, dependencies, development dependencies, and configuration settings for tools like mypy and pytest.
- **[README.md](backend/README.md.driver.md)**: The `README.md` file in the `python-backend` codebase provides comprehensive instructions for setting up and developing a FastAPI backend project, including requirements, local development setup with Docker and Poetry, backend testing, and database migrations.
- **[tests-start.sh](backend/tests-start.sh.driver.md)**: The `tests-start.sh` file is a shell script that sets up the environment and executes pre-start and test scripts for the `python-backend` codebase.
- **[tst.py](backend/tst.py.driver.md)**: The `tst.py` file contains tests for the `LlmConfig` class methods, specifically testing the `default` and `from_name` methods for both valid and invalid model names.
