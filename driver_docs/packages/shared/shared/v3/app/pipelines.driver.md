## Folders
- **[performance_tests](pipelines/performance_tests.driver.md)**: The `performance_tests` folder in the `python-backend` codebase contains the `smart_instruction.py` file, which is used to conduct performance tests on smart instruction pipelines by generating and processing requests with different LLM clients to evaluate and compare their execution times.

## Files
- **[__init__.py](pipelines/__init__.py.driver.md)**: The `__init__.py` file in the `python-backend` codebase initializes the `pipelines` package by importing and exposing various pipeline request and response classes, such as `InlineEditPipelineRequest`, `PipelineRequest`, and `ReformatPipelineResponse`.
- **[abbreviate_page_content.py](pipelines/abbreviate_page_content.py.driver.md)**: The `abbreviate_page_content.py` file implements a pipeline for summarizing page content before and after a cursor position using a language model client, with support for concurrent processing of text chunks.
- **[chat.py](pipelines/chat.py.driver.md)**: The `chat.py` file implements a chat pipeline for handling requests and responses at the `/chat` endpoint, including managing message history and interacting with an LLM client.
- **[inline_edit.py](pipelines/inline_edit.py.driver.md)**: The `inline_edit.py` file defines the `InlineEditPipelineRequest` and `InlineEditPipelineResponse` classes, which handle the processing of inline edit requests using a language model client, including message history management and tool usage.
- **[pipeline_request.py](pipelines/pipeline_request.py.driver.md)**: The `pipeline_request.py` file defines an abstract base class `PipelineRequest` for handling pipeline requests, including session management and data sourcing, with support for synchronous and asynchronous operations.
- **[pipeline_response.py](pipelines/pipeline_response.py.driver.md)**: The `pipeline_response.py` file defines a `PipelineResponse` class that models a response from a pipeline, including handling references and fixing mermaid syntax in the final response.
- **[reformat.py](pipelines/reformat.py.driver.md)**: The `reformat.py` file defines classes for handling reformatting requests and responses in a pipeline, utilizing a language model client to process and stream reformatting tasks based on specified format kinds.
- **[smart_instruction.py](pipelines/smart_instruction.py.driver.md)**: The `smart_instruction.py` file implements a pipeline for processing user prompts and page content using a language model client, with capabilities for both synchronous and asynchronous operations, including message history management and tool integration.
