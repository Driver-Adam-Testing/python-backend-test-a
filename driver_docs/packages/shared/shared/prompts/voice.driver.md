
## Files
- **[__init__.py](voice/__init__.py.driver.md)**: The `__init__.py` file in the `python-backend` codebase initializes the `voice` package by importing the `copy_editor` and `software_engineer` modules.
- **[copy_editor.py](voice/copy_editor.py.driver.md)**: The `copy_editor.py` file contains a prompt for a technical copy editor, outlining detailed instructions for editing technical documents to ensure clarity, conciseness, and relevance.
- **[operator.py](voice/operator.py.driver.md)**: The `operator.py` file outlines a series of questions and options to define a pipeline involving content creation, criticism, and copy editing, along with presets for various document types.
- **[software_engineer.py](voice/software_engineer.py.driver.md)**: The `software_engineer.py` file defines a voice prompt for a system role, emphasizing expertise in software engineering and a focus on factual writing based on recent data.
