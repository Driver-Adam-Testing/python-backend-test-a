## Folders
- **[utils](src/utils.driver.md)**: The `utils` folder in the `python-backend` codebase contains utility files for AWS S3 interactions and environment configuration management using Pydantic.

## Files
- **[main.py](src/main.py.driver.md)**: The `main.py` file in the `python-backend` codebase handles AWS SNS-triggered S3 events for asset onboarding, including fetching secrets, generating presigned URLs, and interacting with an onboarding service using Auth0 authentication.
