
## Files
- **[__init__.py](usage/__init__.py.driver.md)**: Empty file (no analyzable contents).
- **[llm_session.py](usage/llm_session.py.driver.md)**: The `llm_session.py` file in the `python-backend` codebase defines the `LLMUsageSession` class, which manages the lifecycle of a usage session for a language model, including starting and ending sessions, sending usage events to AWS, and computing usage metrics.
- **[usage_service.py](usage/usage_service.py.driver.md)**: The `usage_service.py` file in the `python-backend` codebase implements a service for managing usage events, issuing usage credits, retrieving usage balances and summaries, and fetching usage charges for organizations.
- **[utils.py](usage/utils.py.driver.md)**: The `utils.py` file contains utility functions for converting between bytes and source lines of code (SLOC) using a predefined conversion factor.
