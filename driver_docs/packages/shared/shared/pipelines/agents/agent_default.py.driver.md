### run_agent_default 
The `run_agent_default` function creates and runs an agent based on the provided configuration and session, returning the agent's response and search results.
- **Inputs**:
    - `input`: An instance of `PipelineStepConfiguration` containing the configuration for the agent, such as scope, model, iterations, tools, and response format.
    - `llm_usage_session`: An instance of `LLMUsageSession` that tracks the usage session for the language model.
- **Control Flow**:
    - Create an agent using the `create_agent` function with parameters from the `input` and `llm_usage_session`.
    - Iterate over system prompts generated by `input.create_system_prompts()` and add each to the agent's message queue.
    - Add a predefined software engineer message to the agent's message queue.
    - Invoke the agent with the input prompt converted to a string and store the response.
    - Check if the response is not a string and has a `to_markdown` method, converting it to markdown if applicable.
    - Return a `PipelineStepResponse` containing the agent's ID, the processed response, and any search results.
- **Output**:
    - A `PipelineStepResponse` object containing the agent's ID, the result of the agent's invocation, and any search results obtained during the process.
