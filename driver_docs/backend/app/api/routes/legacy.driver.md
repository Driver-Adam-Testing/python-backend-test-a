
## Files
- **[api_types.py](legacy/api_types.py.driver.md)**: The `api_types.py` file defines GraphQL types for a Git provider and a Git repository using the Strawberry library.
- **[auth0.py](legacy/auth0.py.driver.md)**: The `auth0.py` file in the `python-backend` codebase provides functions for managing Auth0 organizations and users, including creating, retrieving, and deleting organizations, while handling authentication token refreshes and logging errors.
- **[document_set.py](legacy/document_set.py.driver.md)**: The `document_set.py` file in the `python-backend` codebase defines various data structures and functions for managing and retrieving document sets, including content descriptions, quickstart guides, and code metadata, from a database and S3 storage.
- **[logging_extension.py](legacy/logging_extension.py.driver.md)**: The `logging_extension.py` file defines a `LoggingExtension` class that logs the first 128 characters of a GraphQL query execution context.
- **[mutations.py](legacy/mutations.py.driver.md)**: The `mutations.py` file in the `python-backend` codebase defines GraphQL mutations for managing application notes, documents, and codebase uploads, including operations for updating, deleting, and generating upload URLs.
- **[orm_ops.py](legacy/orm_ops.py.driver.md)**: The `orm_ops.py` file contains functions for retrieving derived content by ID and checking access permissions based on various identifiers within a session.
- **[queries.py](legacy/queries.py.driver.md)**: The `queries.py` file defines a set of GraphQL query endpoints using the Strawberry library, including operations for fetching organization details, document sets, codebase trees, user information, connected Git providers, and repositories by Git provider.
- **[s3.py](legacy/s3.py.driver.md)**: The `s3.py` file implements the `S3BucketAccess` class, which provides methods for interacting with an S3 bucket, including uploading, retrieving, and deleting files, using hashed organization IDs for bucket naming.
- **[scalars.py](legacy/scalars.py.driver.md)**: The `scalars.py` file defines custom scalar types for JSON, ID, and NodeType using the Strawberry library to handle serialization and parsing in a GraphQL API.
- **[schema.py](legacy/schema.py.driver.md)**: The `schema.py` file defines a GraphQL schema using Strawberry for a FastAPI application, including custom context and logging extensions, and sets up GraphQL routers with specific configurations.
- **[tree.py](legacy/tree.py.driver.md)**: The `tree.py` file in the `python-backend` codebase defines a function to construct a tree representation of a codebase's directory and file structure using SQLModel and Strawberry.
