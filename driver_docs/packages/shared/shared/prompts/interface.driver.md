
## Files
- **[__init__.py](interface/__init__.py.driver.md)**: The `__init__.py` file in the `python-backend` codebase initializes the `interface` package by importing modules such as `batch_tools`, `maximum_iterations`, `technical_context_interface`, and `think_before_you_speak`.
- **[batch_tools.py](interface/batch_tools.py.driver.md)**: The `batch_tools.py` file contains a system prompt that instructs the execution of multiple tools in iterations without inventing or using undefined functions, and explicitly advises against invoking the `multi_tool_use.parallel` function.
- **[iterations.py](interface/iterations.py.driver.md)**: The `iterations.py` file defines prompt messages for different stages of an iterative process, guiding the execution of tools and the formulation of responses based on retrieved context.
- **[maximum_iterations.py](interface/maximum_iterations.py.driver.md)**: The `maximum_iterations.py` file defines a prompt template and provides functions to render this prompt as a string or a dictionary message, indicating the maximum number of iterations allowed to solve a user's problem.
- **[technical_context_interface.py](interface/technical_context_interface.py.driver.md)**: The `technical_context_interface.py` file defines a system message prompt that instructs a response to be based solely on technical context, delaying final answers until sufficient context is provided and ensuring responses are relevant and supported by source documentation.
- **[think_before_you_speak.py](interface/think_before_you_speak.py.driver.md)**: The `think_before_you_speak.py` file defines a prompt message that instructs the system to include a thought explanation for each batch of tool calls, ensuring the user is informed about the thought process behind these calls.
