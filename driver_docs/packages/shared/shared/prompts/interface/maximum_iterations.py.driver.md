# Purpose
This code provides a narrow functionality focused on generating a formatted message string and packaging it into a dictionary. It consists of a template string `PROMPT` that includes a placeholder for the number of iterations, and two functions: `render_prompt` and `render_message`. The `render_prompt` function takes an integer `max_iterations` as an argument and returns the `PROMPT` string with the placeholder replaced by the provided number of iterations. The `render_message` function builds upon this by returning a dictionary with a fixed key-value pair, where the value is the formatted prompt string generated by `render_prompt`. This code is likely part of a larger system where such messages are used to communicate system constraints or instructions to users or other components.
# Global Variables

---
### PROMPT 
- **Type**: `str`
- **Description**: The variable `PROMPT` is a string template that includes a placeholder for the number of maximum iterations. It is designed to be formatted with a specific integer value to create a complete message.
- **Use**: This variable is used as a template to generate a message indicating the maximum number of iterations allowed for solving a user's problem.


# Functions

---
### render_message 
The function `render_message` creates a dictionary with a system role and a formatted prompt message based on the maximum number of iterations.
- **Inputs**:
    - `max_iterations`: An integer representing the maximum number of iterations allowed for solving a problem.
- **Control Flow**:
    - The function calls `render_prompt` with `max_iterations` as an argument to get a formatted string.
    - It constructs a dictionary with 'role' set to 'system' and 'content' set to the result of `render_prompt`.
    - The function returns the constructed dictionary.
- **Output**:
    - A dictionary with two keys: 'role', which is set to 'system', and 'content', which contains a formatted string indicating the maximum number of iterations.


---
### render_prompt 
The function `render_prompt` formats a predefined prompt string with a specified number of maximum iterations.
- **Inputs**:
    - `max_iterations`: An integer representing the maximum number of iterations to be included in the prompt.
- **Control Flow**:
    - The function takes an integer input `max_iterations`.
    - It converts `max_iterations` to a string and substitutes it into the `PROMPT` template using the `format` method.
    - The formatted string is then returned.
- **Output**:
    - A string that contains the formatted prompt with the specified number of maximum iterations.
