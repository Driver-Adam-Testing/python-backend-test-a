## Folders
- **[core](git_providers/core.driver.md)**: The `core` folder in the `python-backend` codebase contains configuration-related files for Git provider applications, including a Pydantic model for configuration details and a function for loading settings, particularly for GitLab Enterprise Self-Managed providers.
- **[oauth](git_providers/oauth.driver.md)**: The `oauth` folder in the `python-backend` codebase contains the `gitlab_oauth_strategy.py` file, which implements the GitLab OAuth strategy for managing authorization and token processes.
- **[providers](git_providers/providers.driver.md)**: The `providers` folder in the `python-backend` codebase contains the `gitlab_provider.py` file, which implements the `GitLabProvider` class for managing GitLab OAuth, access tokens, repository operations, and AWS integration.
- **[resources](git_providers/resources.driver.md)**: The `resources` folder in the `python-backend` codebase contains the `gitlab_resources.py` file, which provides functionality for interacting with GitLab, such as fetching repositories and retrieving project details.
- **[utils](git_providers/utils.driver.md)**: The `utils` folder in the `python-backend` codebase contains utility files for handling Git provider errors and generating codebase metadata.
