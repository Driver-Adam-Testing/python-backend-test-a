## Folders
- **[pipelines](app/pipelines.driver.md)**: The `pipelines` folder in the `python-backend` codebase contains various Python scripts and a subfolder for performance testing, all of which are designed to implement and manage different types of data processing pipelines using language model clients, including chat, inline editing, reformatting, and smart instruction functionalities.
- **[static](app/static.driver.md)**: The `static` folder in the `python-backend` codebase contains subfolders for enumerations, message processing, response type handling, and utility tools, each with specific Python files for managing content formats, technical documentation, response classes, and utility functions.
