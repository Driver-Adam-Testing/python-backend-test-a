## Folders
- **[claude](models/claude.driver.md)**: The `claude` folder in the `python-backend` codebase contains a `helpers.py` file that provides utility functions for handling tool prompts, parsing XML responses, and formatting tool results.
- **[openai](models/openai.driver.md)**: The `openai` folder in the `python-backend` codebase contains a file, `file_search.py`, which implements a function to query and summarize documents using OpenAI's API with tools like file search and code interpreter.

## Files
- **[__init__.py](models/__init__.py.driver.md)**: Empty file (no analyzable contents).
- **[llm_model_config.toml](models/llm_model_config.toml.driver.md)**: The `llm_model_config.toml` file in the `python-backend` codebase specifies configuration details for various language models from providers like OpenAI, Anthropic, and Google, including model IDs, context window sizes, maximum output tokens, and system prompts.
- **[llm_models.py](models/llm_models.py.driver.md)**: The `llm_models.py` file defines configurations for language model providers and system prompts, and includes a `ModelConfig` class for loading model configurations from a TOML file.
